Solara Cover Studio — an offline web app that turns any photo and caption into GTA 6-style multi-panel cover art and exports it as a PNG in 1080×1080, 1080×1350 or 1920×1080. Load your own photos (or the built-in samples), pick a layout, crop and position each panel, write the caption, choose a Vice City sunset or neon colour grade, and export.

## Run it

```sh
python3 -m http.server 8080 --directory app
# then open http://localhost:8080 in desktop Chrome
```
